# Продолжительность вахты: установка

Без миграции SQLite и без изменения прав VIP. Нужен уже установленный openpyxl.

На сервер загрузить:

- rotation_duration.py
- report_refresh_store.py
- routes/service_reports.py
- routes/report_refresh.py
- templates/service.html
- static/rotation_duration.js
- static/report_refresh.js

После замены перезапустить vs-complect. Существующие data, .env и базу не заменять.

В существующем проекте Google Apps Script:

1. Добавить файл rotation_duration.gs из integrations.
2. Обновить существующий report_refresh.gs из integrations.
3. Сохранить. Используется уже существующий минутный триггер processReportRefreshRequests, новый не создавать.

Файлы planned_departures.gs и shift_attendance.gs остаются в проекте: используются их функции и список объектов.
Ключ VECTOR_ROTATION_ID_KEY создаётся автоматически при первом запросе. Не удалять и не менять: он обеспечивает одинаковый код человека в разных месяцах и объектах. ФИО на сервер не передаются; коды всё равно следует считать защищёнными персональными данными.

В VIP открыть «Продолжительность вахты», выбрать период и когорту, нажать «Обновить данные». За запуск обрабатывается несколько табелей последовательно: после трёх минут новый табель не начинается. Каждый импорт сохраняет прогресс на сервере, следующий минутный запуск продолжает очередь. Одновременные обработчики исключаются блокировкой. Время зависит от Google; страница может быть закрыта. Обычные отчёты очереди имеют приоритет. Повторное «Показать» читает сохранённые данные быстро, без запросов в Google.

Месяц публикуется только после обработки всех его объектов. Недоступные источники отмечаются предупреждением. Старый опубликованный месяц остаётся доступен до завершения нового. Исторические и текущие данные пересчитываются кнопкой; отдельного периодического пересчёта этого отчёта нет.

Новые сводки хранятся в data/rotation_duration (не коммитить). При резервном копировании сохранять эту папку вместе с другими данными.

Проверка: оба варианта, шесть вкладок, одинаковые числа на экране и в Excel, предупреждения при отсутствующем месяце. Пользователь без VIP не должен открывать страницу или API.
